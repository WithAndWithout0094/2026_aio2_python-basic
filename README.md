## 🧭 지향점

- 만드는 사람과 쓰는 사람 사이의 **번역가**가 되는 것
- "어떻게 동작하는가"가 아니라 — **무엇을 가능하게 하는가**를 먼저 묻는 것
- 완성된 척하지 않고, **과정을 공개하며** 자라는 것
