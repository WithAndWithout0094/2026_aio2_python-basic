SCENE 2

자료구조 4형제 — 값을 묶는 큰 가구

변수는 물건 하나를 넣는 창고 칸 — 이제 값 여러 개를 한 이름표 아래 묶는 큰 가구가 필요하다 = 자료구조 data structure
📚 서가 한 줄 — 리스트 list
[값, 값] 대괄호 — 순서 있음, 자유롭게 수정 📦 밀봉 상자 — 튜플 tuple
(값, 값) 소괄호 — 순서 있음, 수정 불가
🗂 도서 카드 — 딕셔너리 dict
{키: 값} 중괄호 — 이름표(키)로 값을 꺼냄 🧺 중복 없는 회수함 — 셋 set
{값, 값} 중괄호 — 중복 자동 제거, 순서 없음
💡 이번 편은 속성 과정에서 통째로 빠지기 쉬운 편이다.
하지만 실제 코드의 데이터는 거의 전부 이 4형제 안에 담긴다 — 급류를 탈 가치 충분! (이 밖에도 더 있다)

튜플 — 밀봉 상자, 그리고 가변 vs 불변

print(shelf[1])

SCENE 11

함정 카드 — 다들 여기서 한 번씩 빠진다

⚠️ 함정 1 — 3권이니까 마지막은 3번? 없는 칸을 열면 IndexError
3권짜리 서가의 칸은 0·1·2번 — shelf[3]은 IndexError!
마지막 칸은 항상 len - 1번. 헷갈리면 그냥 [-1]을 쓰자.
⚠️ 함정 2 — 키는 글자 하나까지 정확히, 없는 키를 열면 KeyError
book["Title"] → KeyError — "Title"과 "title"은 남남!
EP.01의 "파이썬은 대소문자를 구분한다"가 여기서도 적용된다.
⚠️ 함정 3 — 밀봉된 것은 뜯을 수 없다: 튜플도, 문자열도
sealed[0] = "파이썬 급류"도 motto[0] = "물"도 TypeError — 오류문까지 쌍둥이!
둘 다 불변이라서 그렇다. 바꾸고 싶으면 새로 만들어 다시 넣는 수밖에 없다.
