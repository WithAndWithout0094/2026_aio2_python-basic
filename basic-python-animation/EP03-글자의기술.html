SCENE 7

count와 find — 세고, 찾고

shelf = "SF-SF-역사-SF-요리" print(shelf.count("SF")) # → 3 몇 번 나오는지 센다 print(shelf.find("역사")) # → 6 처음 나오는 칸 번호(인덱스) print(shelf.find("시집")) # → -1 없으면 에러가 아니라 -1!
⚠️ find가 돌려주는 값은 인덱스 — 역시 0부터 센 번호.
못 찾으면 조용히 -1 — "없음"의 신호가 -1이라는 것, 기억해 두세요.

SCENE 9

f-string 미세 조정 — 정렬과 자릿수

🎛️ 중괄호 안에 콜론(:) — {값:지시}
구멍의 미세 조정 옵션 = 형식 지정
 형식 지정 format spec
print(f"[{2021:>10}]") # → [ 2021] 오른쪽 정렬 print(f"[{2021:<10}]") # → [2021 ] 왼쪽 정렬 print(f"[{2021:^10}]") # → [ 2021 ] 가운데
print(f"{1048576:,}") # → 1,048,576 천 단위 콤마 print(f"{3.14159:.2f}") # → 3.14 소수점 둘째 자리까지 print(f"[{1024:>7,}]") # → [ 1,024] 조합도 된다!

SCENE 11

함정 카드 — 다들 여기서 한 번씩 빠진다

⚠️ 함정 1 — 인덱스는 0부터. 첫 글자는 [1]이 아니다
title[1] → 이 (두 번째 글자!) · 첫 글자는 title[0] → 파
칸 번호표는 0번부터 — 1번은 두 번째 칸이다.
⚠️ 함정 2 — 슬라이싱 끝 번호는 미포함
title[0:3] → 파이썬 (0, 1, 2번 칸까지 — 3번 칸은 물 건너편!)
물은 끝 수문 앞에서 멈춘다 — [시작:끝]의 끝은 열리지 않는 문.
⚠️ 함정 3 — 문자열은 불변. 칸을 직접 못 바꾼다
title[0] = "C" → TypeError — 통짜 선반은 칸 하나만 도려낼 수 없다!
바꾸려면 title = title.replace("파", "C") — 새 선반을 통째로 만들어 다시 넣기.
